# 🚗 Fast Cars Detection & Tracking

> Программное обеспечение для обнаружения и отслеживания быстродвижущихся объектов в режиме реального времени.

## 🛠 Стек технологий
* **Язык:** Python
* **Детекция:** YOLOv8 (Ultralytics)
* **Трекинг:** ByteTrack
* **Обработка видео:** OpenCV
* **Интерфейс:** PyQt6
